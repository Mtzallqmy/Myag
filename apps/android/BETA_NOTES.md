# وكيل Android — 0.1.0 Beta 1

نسخة Android أصلية أولية: Kotlin / Jetpack Compose، Android 8.0+ (API 26)، target API 36، متوافقة مع ARM64. واجهات التطبيق لا تستخدم WebView أو Capacitor. الشيفرة المدارة DEX مستقلة عن المعمارية؛ أي مكتبات native مقيدة بـarm64-v8a ويمنع CI مكتبات 32-bit.

## متاح للتجربة
- إنشاء حساب عبر Supabase (قد يلزم تأكيد البريد)، تسجيل الدخول والخروج، تجديد الجلسة، وتخزينها مشفرة بمفتاح Android Keystore.
- سجل المحادثات، محادثة جديدة، اختيار نموذج للمحادثة الجديدة، ردود SSE، إيقاف الطلب وإعادة التوليد، Markdown ونص قابل للنسخ، اسم النموذج ورسائل fallback.
- إضافة وتعديل وحذف واختبار المزود واكتشاف النماذج واختبار نموذج منفرد؛ يحفظ الخادم الرموز مشفرة.
- قائمة المشاريع، إنشاء مشروع فارغ، عرض ملفات المشروع وأرقام الأسطر، البحث وAsk Project.
- قراءة المهام والموافقات والتكاملات والذاكرة والإشعارات والسجل من API الحالي، مع قرار موافقة صريح قبل تنفيذ الموافقة.
- واجهة عربية RTL، اختيار الإنجليزية والوضع الليلي/النهاري، Room للقراءة المؤقتة عند انقطاع الاتصال، DataStore للإعدادات، WorkManager لفحص الاتصال المؤجل فقط.

## حدود هذه البيتا
- لم تُنفذ تجربة جهاز حقيقي أو محادثة بمزود فعلي أو اختبار بث BotKeep مع نموذج فعلي؛ نجاح البناء لا يثبت هذه السيناريوهات.
- رفع ZIP واستيراد GitHub وربط OAuth وMCP وإدارة الأدوار والخطط والإحصاءات وتحرير الذاكرة والإشعارات وتشغيل مهام الوكيل واستئنافها الكامل ليست واجهات مكتملة هنا. المهام للمتابعة فقط، وWorker الخادم ما زال معطلاً.
- اختيار النموذج اليدوي عند إنشاء المحادثة فقط؛ تعديل التوجيه لمحادثة موجودة قيد النقل.
- لا يوجد محرر شيفرة أو تمييز نحوي متقدم أو واجهة diffs كاملة بعد؛ عرض Markdown/ملفات نصية فقط.
- قاعدة Wakeel المختارة لا تحتوي نقل المستخدمين/التاريخ من قاعدة المشروع الأصلية غير المتاحة.
- هذه الحزمة تستخدم شهادة Android اختبارية، وليست توقيع إنتاج. قد يتطلب بناء بيتا لاحق إزالة النسخة السابقة إذا اختلفت الشهادة. لم توفَّر مفاتيح توقيع إصدار نهائي.

يتصل التطبيق بـAPI: https://wvcvrb.bot-keep.xyz/. لا يتضمن مفاتيح Service Role أو تشفير المزودين أو أسرار GitHub/MCP. مفتاح Supabase publishable مخصص للتسجيل العام فقط.

ينفذ CI اختبارات محلل SSE، وAndroid Lint، وبناء APK، وفحص التوقيع وminSdk/targetSdk والمكتبات قبل إنشاء GitHub prerelease. نتائج التنفيذ الفعلية متاحة في Actions؛ اختبار الأداء على جهاز المستخدم لا يزال مطلوبًا.
