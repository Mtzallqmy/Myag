# وكيل Android — 0.1.0 Beta 6

## تغييرات Beta 6
- واجهة GitHub فعلية: PAT مشفر في الخادم، اكتشاف ومزامنة المستودعات، قراءة المشكلات وطلبات الدمج، استيراد snapshot بموافقة صريحة وفصل الحساب. كتابة المستودع ما زالت عبر سياسة الوكيل والموافقات.
- واجهة MCP فعلية: Streamable HTTP، Bearer اختياري، OAuth في متصفح النظام، اكتشاف الأدوات والموارد، مراجعة وتفعيل الصلاحيات مع الحفاظ على الموافقة، واستدعاء يدوي بمعاملات JSON وموافقة صريحة.
- إصلاح فصل GitHub الذي كان يحاول DELETE بصلاحيات عميل SELECT-only، وإظهار أخطاء مزامنة قاعدة البيانات بدل نجاح شكلي.
- فصل Telegram يفحص Webhook الفعلي حتى بعد فشل تعطيل سابق ولا يمس Webhook يخص تطبيقًا آخر.
- حزمة مستقلة `com.wakeel.app.beta6` لتجنب تعارض شهادات البيتا. ميزات Beta 5 مستمرة.
- التكاملات تحتاج رموزًا وخوادم فعلية من المستخدم؛ بناء الشيفرة لا يثبت اختبار كل خدمة حية. OAuth يعود عبر صفحة callback بالخادم ثم تحديث يدوي؛ App Links تلقائية لم تكتمل.

## تغييرات Beta 5
- شاشة الوكلاء والاتصالات: فحص مباشر للخادم والمزودين والنماذج والمشغّل، وأدوار الوكلاء الفعلية من المحرك الحالي. يظل التشغيل مرتبطًا بتفعيل worker ونشر API الجديد.
- إصلاح اختبار النموذج (`modelId`)، جلب النماذج على دفعات حتى 3000 بدل أول 100، ترتيب الرسائل الحديثة، وتسلسل عمليات القراءة بدل إسقاطها أثناء الانشغال.
- أداء المحادثة: عدم إعادة تحليل Markdown القديم مع كل جزء بث، وعدم إعادة فرز كل النماذج مع كل تغير حالة، ومنع تجاوز حد الرسالة بدل اقتطاع صامت.
- وسائط محلية: بصمة SHA-256 بقراءة متتابعة دون تحميل كامل الملف، صور بأبعاد ومعاينة مصغرة، فيديو بمدة وأبعاد ولقطة أولى على Android 8.1+، PDF بعدد الصفحات ومعاينة أول صفحة. Android 8.0 يقرأ بيانات الفيديو دون استخراج اللقطة.
- تخزين خاص: رفع صريح لصور وفيديو وPDF وملفات حتى 50MiB مباشرة إلى Supabase، تقدم وإلغاء وفحص الحجم والنوع على الخادم. لا تمر الملفات الكبيرة عبر ذاكرة BotKeep API.
- تحليل الصور: إرفاق حتى أربع معاينات JPG إلى SSE الفعلي، مع قصر التوجيه على نماذج vision. الفيديو وPDF يمثلان لقطة/صفحة فقط؛ لا يدّعي التطبيق تحليل جميع الصفحات أو الصوت.
- حماية التخزين: RLS للمالك، روابط رفع محددة المسار، حساب حصص ذري، والعمليات المعلقة تحجز 50MiB حتى التحقق. الحذف ينتظر انتهاء رابط الرفع (ساعتان) لمنع إعادة رفع غير محسوبة.
- حزمة `com.wakeel.app.beta5` لتجنب تعارض شهادة البيتا؛ تثبت بجانب Beta 4 ويلزم الدخول مجددًا. هذه نسخة اختبار؛ لا تعني اكتمال تكافؤ الويب أو اختبار كل تكامل خارجي.

## تغييرات Beta 4
- حزمة جديدة `com.wakeel.app.beta4` باسم «وكيل · Beta 4» لتجنب تعارض شهادة تحديث البيتا السابقة؛ يمكن تثبيتها بجانب Beta 3. يلزم الدخول وتعيين PIN مجددًا.
- مختبر ملفات محلي: Android document picker وRoom وUTF-8 محدودة، SHA-256 واكتشاف اللغة وإشارات الأطر والدوال وتحذيرات أنماط الأسرار وTODO. لا تُرفع الملفات تلقائيًا ولا تُشغَّل الشيفرة. حتى 10 ملفات في المرة و600KB للملف و50 ملفًا محفوظًا.
- معالجة محلية: تنسيق JSON والتحقق منه وتنظيف المسافات وتنقيح أنماط الأسرار وتصدير نسخة مع حفظ الأصل؛ بحث محلي وإرفاق صريح للمحادثة بعد مراجعة المحتوى.
- استيراد ZIP بموافقة الرفع إلى التخزين الخاص والفهرسة الحالية: 3MiB مضغوط و200 مدخل و8MiB إجمالي معلن؛ رفض traversal والروابط الرمزية وZIP bombs.
- تحسين المحادثة: بطاقات شيفرة أصلية مع النسخ واللغة، حالة بث، متابعة أحدث الردود أو التوقف عند السحب، اقتراحات بداية وانتقالات خفيفة.
- نماذج: بحث ومرشحات مجانية/مدفوعة/غير معروفة وقدرات وفرز السياق والسعر واختبار نموذج منفرد. السعر الفارغ لا يُصنّف مجانيًا. توجيه AUTO/PREFER_FREE/CODING/LONG_CONTEXT للمحادثة الجديدة.
- تشغيل الوكيل بالأوضاع والأعماق الحالية عندما يُفعّل Worker، مع تقدم وخطوات وفروقات ونتائج تحقق وإلغاء وموافقات. عند غياب Runtime معزول تكون الاختبارات UNAVAILABLE. المهام الجاري تنفيذها أثناء إعادة تشغيل الخادم تظهر INTERRUPTED؛ استئناف خطواتها الكامل يحتاج تطويرًا إضافيًا.
- تليجرام: ربط واختبار توكن مشفر على الخادم، تفعيل Webhook بموافقة صريحة، مستخدم خاص محدد بـTelegram User ID، طابور PostgreSQL دائم مع Lease ومنع التكرار وعدم إعادة الإرسال العمياء عند الشك في التسليم. يستخدم بوابة النماذج نفسها دون تنفيذ أو تعديل المستودعات.
- يحتاج تليجرام وZIP وواجهة تشغيل الوكيل نشر الخادم الجديد. `PUBLIC_API_ORIGIN` يجب أن يطابق HTTPS الفعلي. يحتاج الرد مزودًا صالحًا؛ PREFER_FREE قد ينتقل إلى مدفوع عند غياب مجاني.
- التحليل تقريبي ولا يعادل AST/LSP أو تدقيقًا أمنيًا مضمونًا. PDF/OCR والتحليل الثنائي غير مدعومين هنا. تفاصيل المقترحات المستقبلية في docs/BETA_4_DEVELOPMENT.md؛ ليست وظائف منفذة.

## تغييرات Beta 2 السابقة
- توضيح خطأ كلمة المرور بدل `HTTP_401` المبهم، مع زر إظهار/إخفاء كلمة المرور.
- حساب المالك الحالي مؤكّد ومخصص له SUPER_ADMIN؛ لا يلزم تأكيد بريد جديد لهذا الحساب. لا تُضمَّن كلمة مروره أو الجلسة أو مفاتيح الخادم في APK.
- بعد الدخول الأول يمكن تعيين رمز داخلي من 6 إلى 12 رقمًا من «المزيد». يقفل التطبيق عند مغادرته وعند إعادة التشغيل، وتبقى الجلسة مشفّرة في Android Keystore. يحفظ مشتق PIN مشفرًا، مع PBKDF2 وملح عشوائي وتقييد المحاولات. نسيان PIN يمسح الجلسة والرمز ويعيد شاشة الدخول.
- يمكن تغيير كلمة مرور الحساب من «المزيد» داخل جلسة مصادق عليها. الرمز الداخلي خاص بهذا الهاتف ولا يحل محل مصادقة الخادم.
- إعادة تعيين كلمة مرور المالك واختبار تسجيل دخوله عبر الخادم نُفّذا بالفعل. أدلة قبول بقية الوظائف في docs/ANDROID_BETA_2_ACCEPTANCE.md.

نسخة Android أصلية أولية: Kotlin / Jetpack Compose، Android 8.0+ (API 26)، target API 36، متوافقة مع ARM64. واجهات التطبيق لا تستخدم WebView أو Capacitor. الشيفرة المدارة DEX مستقلة عن المعمارية؛ أي مكتبات native مقيدة بـarm64-v8a ويمنع CI مكتبات 32-bit.

## متاح للتجربة
- إنشاء حساب عبر Supabase (قد يلزم تأكيد البريد)، تسجيل الدخول والخروج، تجديد الجلسة، وتخزينها مشفرة بمفتاح Android Keystore.
- سجل المحادثات، محادثة جديدة، اختيار نموذج للمحادثة الجديدة، ردود SSE، إيقاف الطلب وإعادة التوليد، Markdown ونص قابل للنسخ، اسم النموذج ورسائل fallback.
- إضافة وتعديل وحذف واختبار المزود واكتشاف النماذج واختبار نموذج منفرد؛ يحفظ الخادم الرموز مشفرة.
- قائمة المشاريع، إنشاء مشروع فارغ، عرض ملفات المشروع وأرقام الأسطر، البحث وAsk Project.
- قراءة المهام والموافقات والتكاملات والذاكرة والإشعارات والسجل من API الحالي، مع قرار موافقة صريح قبل تنفيذ الموافقة.
- واجهة عربية RTL، اختيار الإنجليزية والوضع الليلي/النهاري، Room للقراءة المؤقتة عند انقطاع الاتصال، DataStore للإعدادات، WorkManager لفحص الاتصال المؤجل فقط.

## حدود هذه البيتا
- لم تُنفذ تجربة جهاز حقيقي أو محادثة بمزود فعلي أو اختبار بث BotKeep مع نموذج فعلي؛ نجاح البناء لا يثبت هذه السيناريوهات. اختبار دخول HTTP لا يثبت دورة حياة PIN على جهاز Android.
- ربط GitHub OAuth وMCP وإدارة الأدوار والخطط والإحصاءات وتحرير الذاكرة والإشعارات بالكامل لم تكتمل واجهاتها الأصلية بعد. Worker قد يبقى معطلاً في الاستضافة الحالية. الويب محفوظ مرجعًا؛ لا تمثل البيتا تكافؤًا كاملاً.
- اختيار النموذج اليدوي عند إنشاء المحادثة فقط؛ تعديل التوجيه لمحادثة موجودة قيد النقل.
- لا يوجد محرر شيفرة أو تمييز نحوي متقدم؛ عرض Markdown/ملفات نصية وبطاقات شيفرة وفروقات المهام.
- قاعدة Wakeel المختارة لا تحتوي نقل المستخدمين/التاريخ من قاعدة المشروع الأصلية غير المتاحة.
- هذه الحزمة تستخدم شهادة Android اختبارية، وليست توقيع إنتاج. قد يتطلب بناء بيتا لاحق إزالة النسخة السابقة إذا اختلفت الشهادة. لم توفَّر مفاتيح توقيع إصدار نهائي.

يتصل التطبيق بـAPI: https://wvcvrb.bot-keep.xyz/. لا يتضمن مفاتيح Service Role أو تشفير المزودين أو أسرار GitHub/MCP. مفتاح Supabase publishable مخصص للتسجيل العام فقط.

ينفذ CI اختبارات محلل SSE، وAndroid Lint، وبناء APK، وفحص التوقيع وminSdk/targetSdk والمكتبات قبل إنشاء GitHub prerelease. نتائج التنفيذ الفعلية متاحة في Actions؛ اختبار الأداء على جهاز المستخدم لا يزال مطلوبًا.
